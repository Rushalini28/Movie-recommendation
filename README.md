# 🎬 Movie Recommendation App

## Description
A beginner-friendly Python application that recommends movies based on the user's preferred genre. It also allows users to search for movies and view their genres and ratings.

## Features
- Genre-based movie recommendations
- Search for movies by title
- Display movie genres and ratings
- Sort recommendations by rating
- Simple interactive command-line menu

## Technologies Used
- Python 3
- Lists and dictionaries
- Functions and loops
- Conditional statements
- Sorting and filtering

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the command:

   `python main.py`

## Note
This project uses a predefined movie dataset. The displayed ratings are sample reference values and are not fetched live from a movie database.
